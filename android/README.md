# Haptic MIDI + MP3 (Android)

Аналог макбучной программы: MIDI-ноты и биты MP3 превращаются в вибрацию
вибромотора телефона. Плюс звук синхронно. Ноль внешних SDK-зависимостей
в коде — только AndroidX/Compose из Maven.

Готовый APK: **`HapticMidi-debug.apk`** (ставится напрямую на телефон).

## Возможности

- 🎹 **MIDI** (`.mid`): свой парсер без зависимостей (формат 0/1, карта темпа),
  velocity → амплитуда вибрации, режимы velocity/pitch/drums
- 🔊 **MP3/WAV/M4A/OGG** (`.mp3` и др.): декод через MediaCodec +
  onset-детекция (energy flux + адаптивный порог), сила бита → амплитуда
- Звук вместе с вибрацией (MediaPlayer, темп общий). Вибрация привязана
  к реальной позиции звука, а не к часам: сначала стартует звук —
  больше такого нет, удары идут по позиции трека
- Плейлист, повтор (выбранное / всё / 🔂 / 🔁), прогресс, лог
- Открытие из файлового менеджера («Открыть с помощью»)
- В отличие от мака тут есть **настоящая амплитуда** (1–255) и предустановленные
  щелчки (`EFFECT_HEAVY_CLICK`) для акцентов
- **Буст** 100–300%: множитель силы + тяжёлые клики и двойные импульсы
  для сильных ударов (по умолчанию 150%)
- **Метроном** 40–240 BPM, доли 2/3/4, звук отговорён отдельно — инструмент
  подгонки синхрона (см. ниже). Стук — синтезированный «ток» деревянного блока
  (30 мс, не пищалка); если AudioTrack не завёлся — фолбэк на ToneGenerator.
  Стук идёт в громкость мультимедиа: если не слышно — проверь её
  (текущая пишется в лог при старте метронома)
- **Визуальные доли**: крупные точки ● ○ ○ ○, текущая подсвечивается —
  видно каждую долю без звука
- **Синхрон** −1000…+1000 мс: сдвиг вибрации относительно звука.
  Как подогнать: запусти метроном, слушай клик и чувствуй вибрацию,
  крути «Синхрон» (слайдер работает вживую, кнопки ±10 мс — точная доводка),
  пока не совпадут. Кнопка «Тест: 5 пар» — быстрая проверка.
  Плюс сдвигает вибрацию и при игре файлов (полезно при Bluetooth-наушниках,
  у которых звук опаздывает)

## Установка

1. Скопируй `HapticMidi-debug.apk` на телефон и открой — разреши установку.
2. Или через adb: `adb install -r HapticMidi-debug.apk`

Нужно только разрешение на вибрацию (обычное, спрашивается автоматически).

## Сборка из исходников

Нужны Android SDK (API 34) и JDK 17. На этой машине:

```bash
cd android
/tmp/gradle-dl/gradle-8.7/bin/gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

В Android Studio — просто открыть папку `android/`.
Путь к SDK: `local.properties` (`sdk.dir=...`) — поправь под себя.

Проверено на эмуляторе (Pixel, API 37): MIDI на 8 нот и MP3 на 10 битов
играют без крашей (`adb logcat -s HapticMidi`).

## Структура

- `MainActivity.kt` — UI (Compose), очередь, звук, планирование ударов
- `audio/MidiParser.kt` — парсер SMF, порт `midi_haptic.c`
- `audio/BeatDetector.kt` — MediaCodec-декод + детектор битов, порт `audio_haptic.c`
- `haptics/HapticEngine.kt` — Vibrator: one-shot с амплитудой + EFFECT_CLICK
